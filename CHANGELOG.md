# Manual Focuser
## 1.2.0.0 (2026-10-12)
- Add Manual Focus and Live Focus modes with one MF toolbar icon and three independently dockable panels.
- Capture after focuser movement using NINA autofocus settings; plot HFR by focus position with movement arrows and a labeled minimum.
- Add continuous ROI preview, adjustable exposure, a rolling 120-second HFR history, multi-star tracking and optional star boxes.
- Add zoom, rotation, horizontal flip, Auto Stretch, a 3x3 aberration inspector and target selection with Slew or Slew + Center.
- Keep live frames in MF Image; synchronize original image data to NINA Image on request or after capture/stop, preserving native plate solving and reprocessing consistency.
- Fix aberration preview rendering during repeated toggling and zooming; add viewer diagnostics.
- Update README screenshots and retain the existing Manual Focuser plugin identity. Requires NINA 3.2.0.9001 or later.
